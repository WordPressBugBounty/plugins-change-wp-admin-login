## Plugin artwork

Most SVG/PNG assets under `assets/images/` (admin UI chrome, menu icons, marketing illustrations) are original plugin artwork created for AIO Login, distributed under the same GPLv2-or-later license as the plugin, unless a file-specific notice says otherwise. They are not third-party font files and are not covered by the OFL texts above.

## Plugin artwork

SVG/PNG assets under `assets/images/` (icons, admin UI, marketing illustrations) are original plugin artwork created for AIO Login / Change WP Admin Login, distributed under the same GPLv2-or-later license as the plugin, unless a file-specific notice says otherwise. They are not third-party font files and are not covered by the OFL texts above.
